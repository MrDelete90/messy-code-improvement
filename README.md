# Messy Python Code Improvement

This project shows a messy Python script improved using AI assistance (Cursor AI).

## Files
- **messy_code.py**: the original script with poor names, no spacing and nested if/else
- **improved_code.py**: the cleaned version

## What Was Improved
- Meaningful function and variable names
- Proper spacing and formatting
- Simplified nested if/else using elif
- Replaced the manual loop with `sum()`
- Added docstrings and comments

## Technologies Used
Python, Cursor AI
